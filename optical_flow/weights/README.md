# SEA-RAFT checkpoint

Place the frozen SEA-RAFT checkpoint here as `kitti-S.pth`, or update
`ckpt_path` in the FlowRT-DETR configuration. Checkpoints are intentionally
not committed. Obtain a compatible model from the official
[SEA-RAFT model zoo](https://github.com/princeton-vl/SEA-RAFT#model-zoo).
