# Security Policy

## Supported versions

Security fixes are applied to the latest release and the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature. Do not disclose a
potential vulnerability in a public issue. Include affected files or versions,
impact, reproduction steps, and any suggested mitigation. We will acknowledge
a complete report as soon as practical and coordinate disclosure after a fix.

Model accuracy failures and research limitations are not security issues; use
the bug-report template for those.
